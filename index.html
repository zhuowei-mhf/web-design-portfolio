前端切版實作與網頁設計助教展示

聚焦於語意化 HTML5/CSS 基礎打底、Flexbox/Grid 響應式佈局（RWD）、資料表格排版、表單驗證與 GitHub 專案部署。

檢視實作成果

1. 響應式佈局與 CSS 斷點設計 (RWD)

運用 CSS Flexbox 與 Bootstrap 網格斷點（col-12 col-md-6 col-lg-4），使圖文與資訊卡片在不同螢幕寬度下自然轉換垂直與水平排列，確保行動端無跑版。

行動端優先 (Mobile)

所有區塊在 max-width: 768px 下自動切換單欄流動排版，按鈕與文字點擊範圍符合手指操作人因工程。

桌機版雙欄佈局

運用 flex-direction: row 與 gap 間距設定，維持視覺重心與水平對齊，改善可讀性。

列印排版優化 (Print CSS)

實作 @media print 規則，在列印或匯出 PDF 時自動隱藏導覽列、操作按鈕等無效標籤，保留乾淨資料。

2. 複雜資料表格排版 (Data Table)

取自清大 USR 計畫後台活動與會議列表實作。針對零基礎同學常遇到的「表格破版」、「內容過長截斷」等痛點，建立具備 RWD 滾動保護與語意結構的標準 Table。
